# Sessão 2026-09-15 — M5: Docker/apt tools + sessão persistente

**Milestone**: M5 (`specs/milestones/05-m5-docker-apt-sessao.md`)

## Resumo

Entregues as ferramentas de operação de sistema (docker/apt) sobre o sandbox, o controle de
contexto da sessão persistente (`--resume`, `session_context_bytes`, `Reduce`), e a limpeza
explícita de sessões antigas. Versão → `0.5.0-m5`.

- D-2026-09-15-20..24 em `docs/DECISOES.md` (docker whitelist, apt update/install, redução por
  turnos, --resume/--cleanup, toggles com ask).

  (`30` passado como `time.Duration`); só apareceu rodando a suíte real no WSL.

## O que foi feito

### `internal/tools/docker` (novo)
- Tool `docker`: args `{"subcommand":"ps","args":[...]}`; whitelist fechada de subcomandos
  `{ps, logs, inspect, stats, top, images, port, version, info, restart, stop, start}`; qualquer
  outro subcomando → `*tools.DeniedError` antes de tocar a CLI.
- Sempre vetor `exec.Command("docker", subcommand, args...)` — modelo nunca vira texto de shell.
- `execCommand` injetável (helper-process de `os.Executable()`), fake `docker` via PATH (Linux),
  limites de args (64 args / 1 KiB cada) e saída com buffer limitado.

### `internal/tools/apttools` (novo, atende `internal/tools/package` do spec)
- Tool `apt`: só `update` e `install`; `remove`/`purge`/`upgrade`/`autoremove` → `DeniedError`.
- Pacotes validados por regex `^[a-z0-9][a-z0-9.+_-]*$` (sem opções/paths/globs); vetor
  `apt-get install -y <pkgs...>` ou `apt-get update`; política no loop sempre `ask`.

### Sessão persistente / contexto (SPEC §9, M5)
- `model.Store` ganhou `Reduce(maxBytes)`/`ReduceMessages` (descarta turnos completos, mais
  antigos primeiro, nunca separa tool_calls da tool response) e `SummaryMessage` com marcador
  "[resumo de contexto — nao autoritativo]".
- Loop aplica o orçamento via `session_context_bytes` (0 = off) em Turn/Continue/reload.
- `main.go`: `--resume <id>` reutiliza `sessions/<id>.jsonl` e é recusado com `--reset`;
  `--cleanup <n>` remove explicitamente `*.jsonl` antigos de `sessions/`.
- Config: toggles `docker_tool`/`apt_tool` (default disabled) exigem `approval.default=ask`;
  `--run` incompatível com qualquer um deles.

### Bug encontrado (D-2026-09-15-25)
- `shell.New` com executor nil passava `30` (int) como `time.Duration` = 30ns de timeout; o
  caminho real (`bash -c`) falhava com `context deadline exceeded`. Corrigido para `30*time.Second`.
- Testes de helper agora usam `os.Executable()` (path absoluto) — `cmd.Dir` do sandbox quebrava
  `os.Args[0]` relativo. Corrigido em sandbox, docker e apttools.
