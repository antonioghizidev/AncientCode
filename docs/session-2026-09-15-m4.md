# Sessão 2026-09-15 — M4: Sandbox completo

**Milestone**: M4 (`specs/milestones/04-m4-sandbox-completo.md`) — **concluído**.

## Escopo implementado

- **internal/audit**: `Recorder` append-only JSONL (0600), `Entry` com timestamp/tool/args/status/
  exit_code/output_hash SHA-256/policy/decision/duration/truncated; rotação por tamanho com
  keepCount; `ReadEntries` para inspeção.
- **internal/sandbox/policy**: hard-block normalize-agnostic (regexps em forma normalizada:
  rm-rf/, rm-fr/, rm-r-f/, rm-f-r/, rm-.+-f.*/, of=/dev/, <>dev, mkfs, dd of=/dev/,
  wipefs, fdisk, parted, sudo, chmod-777, format); chaining deny ([;|&] newline $() backtick);
  whitelist `DefaultAllowed` com prefix match; `AllowCommand` + `AllowExecutable` + `DeniedError`.
- **internal/sandbox/executor**: `Executor{workdir, runUser, timeout, maxOut}`, `Result{ExitCode,
  Output, Truncated, Approved, SignedArgs, Duration}`, injectable `execCommand` para testes,
  `su - <runUser> -c` no Linux quando user diferente, `limitedBuffer`, refuse `run_user=root`.
- **shell tool**: refatorado para delegar ao `sandbox.Policy` (hard-block → chaining → whitelist)
  e `sandbox.Executor`; traduz `*sandbox.DeniedError` → `*tools.DeniedError`.
- **Loop audit**: `SetAudit(*audit.Recorder)`; `recordToolCall` após cada tool_call —
  status="executed"/"denied"/"timeout"/"error" com decision=reason; args redigidos via
  `redact.Redact()` antes de gravar; `tools.DeniedError` classifica recusas de segurança.
- **main.go**: `sandbox.NewPolicy`, `sandbox.NewExecutor`, `shell.New(policy, exec)`,
  `audit.NewRecorder` (10MiB, keep 5); `agent.SetAudit(rec)`; versão 0.4.0-m4.
- **testes**: helper-process pattern no executor (sem depender de bash real); requireBash no
  shell (trial-run no Windows); 4-camadas rm -rf / no loop + audit; variants quoted/flags;
  chaining denied; whitelist denies nc; run_user=root denied; audit redacts secret in args.
