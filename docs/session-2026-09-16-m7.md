# Sessão 2026-09-16 — m7 skills

> Resumo exclusivo desta sessão. Metodologia: `specs/methodology.md`.

## Objetivo da sessão

Implementar **M7 — Skills** (SPEC §11.1) no branch `m7-skills`: pacote `internal/skills`,
tool `skill_run` via sandbox (vetor puro), integração no loop (injeção untrusted + interseção do
toolbox), config `skills_dir` e CLI `--skill`/`--verify-skill`. Workflow lento: nada de
commit/push direto na `main`.

## O que foi feito

- **`internal/skills`** (TDD): `ValidateName` (`^[a-z0-9]+(?:-[a-z0-9]+)*$` — sem `.`/`/`/espaços/
  hífens duplos), `Load`/`readSkill` com frontmatter YAML estrito (`KnownFields(true)`, `name`==dir,
  limites 256 KiB SKILL.md / 64 KiB script), `Verify`/stamp `.ancientcode-verified` (hash sha256 de
  SKILL.md + scripts, `origin_hash` cruzado), `ScriptPath`/`VerifyScript` strict-child
  (EvalSymlinks + prefixo), `discoverScripts` (regular, tamanho, ordenado). `Set` de skills ativas
  (insertion order + `HasScripts` + `UnionAllowed`). 14 testes de validação/segurança.
- **`sandbox.ExecutorVector`**: execução por vetor de argumentos **sem shell**; recusa `run_user`
  diferente do atual e `root` (D-2026-09-16-39, sem downgrade silencioso). Fix de teste sob `-race`:
  os testes de captura do helper-process ganharam folga de boot (15s) e o teste de kill passou a
  possuir deadline próprio (1s).
- **`internal/tools/skills` (skill_run)**: vetor puro, `argv` limitado (64 args / 16 KiB), skill
  ativa exigida, script verificado por hash e contido em `scripts/`, `tools.DeniedError` para
  auditoria `denied`. Testes: denies (skill ausente/sem scripts/script desconhecido ou escapando/
  argv grande) + execução real (Linux).
- **Loop**: `SetSkills` (set compartilhado com a tool) + `SetSkill` (valida `allowed_tools` contra o
  registry, fail-closed D-38); `enabledTools()` faz **interseção** do toolbox com a união de
  `allowed_tools` (skill_run à parte, quando há scripts, só em run); `policyFor("skill_run")=ask`;
  system prompt injeta as skills dentro de `[untrusted-tool-output]` (D-41). 6 testes
  (`TestM7*`).
- **Config/CLI**: campo `skills_dir` (default `~/.config/ancientcode/skills`), `tool_timeouts.skill_run`
  (60s default), flags `--skill` (repetível) e `--verify-skill`, registro sempre de `skill_run` no
  reg, `--run` + skill com scripts → recusa na inicialização; versão `0.7.0-m7-ind`.
- **Exemplo YAML** atualizado; SPEC §11.1/M7 marcados implementados.
